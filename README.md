# FarmaLote VDG

Windows Forms inventory interface for tracking medicine lots, quantities, and expiry dates.

## Run in Visual Studio

Open `FarmaLoteVDG.slnx` or `FarmaLoteVDG.csproj` in Visual Studio and run the project. The project targets .NET Framework 4.8.

The sample inventory is stored in memory for demonstration. Changes are lost when the application closes; no database or backend is connected.
